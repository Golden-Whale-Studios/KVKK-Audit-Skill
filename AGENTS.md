# Agent instructions

## KVKK audit

When the user asks for a KVKK audit, a Turkish data-protection or privacy review of the code,
"can I launch in Turkey?", "is my app KVKK compliant?", "KVKK denetimi" or "kişisel veri denetimi":

1. Read `skills/kvkk-audit/SKILL.md` and follow it, including its workflow in
   `skills/kvkk-audit/references/workflow.md`.
2. The skill directory is `skills/kvkk-audit/`. If this file was copied into another project, use the
   folder where the `kvkk-audit` skill is installed instead.

Do not audit from memory: the rules, severities, checklist and report format are defined only in the
skill files.
